# Mangrove Soil Physicochemical Properties and Microbial Diversity Data

This repository contains the dataset used for a study on soil carbon dynamics in mangrove ecosystems under different flooding durations and stand types.

## Dataset

The Excel file includes soil physicochemical properties and microbial alpha-diversity data from mangrove soils collected in Qingmei Port Mangrove Nature Reserve, Sanya, Hainan, China.

## Sampling Design

Samples were collected from two mangrove stand types:

* `N`: Natural mangrove
* `R`: Restored mangrove

Four flooding-duration zones were included:

* 1 h
* 8 h
* 16 h
* 24 h

Each treatment combination includes five replicate transects.

## Data Description

The dataset includes:

* Soil water content
* Total carbon
* Soil organic carbon
* Inorganic carbon
* Microbial biomass carbon
* Soil pH
* Observed ASV richness
* Chao1 richness
* Shannon diversity index
